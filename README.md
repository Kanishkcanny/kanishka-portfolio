
# Kanishka – Beyond the Resume

An AI-powered personal portfolio showcasing my professional journey,
DevOps engineering skills, technical projects and experience.

## About the Project

This project is being developed as a full-stack web application
with a focus on modern development and DevOps practices.

The objective is to build, automate, containerize, deploy and
monitor a real-world application.

## Current Features

- Professional profile homepage
- Career experience timeline
- DevOps project showcase
- Technical skills section
- Responsive desktop and mobile design
- Contact and LinkedIn links

## Run Locally

### Prerequisites
- Node.js
- npm
- Git

### Installation

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173/
